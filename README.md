# investment-screening-skill
基于巴菲特+李嘉诚投资哲学的全球视野高胜率投资股票标的筛选系统 V3.1
一套基于巴菲特与李嘉诚价值投资理念构建的全自动全球投资标的筛选系统，直接输出符合严格标准、可直接买入的股票、基金、债券、石油、大宗商品，无需人工筛选。

**核心目标**
只推荐同时满足以下硬标准的资产：
持有 1/6/12 个月胜率 ≥ 90%
年化收益 ≥ 全球通胀率的 2 倍（税后、扣除成本）
高前瞻性、强安全边际、长周期确定性
低政治风险、无内幕交易异常、非热点炒作标的

**核心特点**
全市场覆盖：美股、港股、A 股、欧股、日股、大宗商品、债券
多语言信息源：全球主流媒体、各国央行、官方公告，交叉验证
政治关联过滤：政客持股、家属交易、公开申报数据筛查
事件权重量化：地缘政治、各国政策、行业影响自动打分
严格去噪规则：不推热点、不炒概念、不采信阴谋论
零幻觉承诺：只采信官方数据、公开披露、双信源验证事实
全自动输出：直接给出可买入标的 + 仓位建议

**适用人群**
追求高胜率、低噪音、强前瞻性的全球长期投资者，省去人工研究与主观判断。

**输出承诺**
若当前无任何标的满足 **≥90% 胜率标准，系统将直接返回“暂无合格标的”**——绝不猜测、绝不编造、绝不乱推。

Global High-Probability Investment Screener
A fully automated global investment selection system built on Buffett & Li Ka‑shing’s value philosophy, designed to directly output actionable stocks, funds, bonds, oil, and commodities that meet strict criteria. No manual screening required.

**Core Objective**
Only recommend assets with:
≥90% win rate over 1‑month / 6‑month / 12‑month holding periods
Annual return ≥ 2× global inflation (after fees and costs)
High forward visibility and strong margin of safety
Low political risk, no insider trading anomalies, no hype

**Key Features**
Global coverage: US, EU, Japan, Hong Kong, China, commodities, bonds
Multi‑language news & policy tracking: cross‑validated mainstream sources only
Politician/insider trading filter: US Congress disclosures, EU transparency registers, official filings
Event‑impact weight matrix: quantifies geopolitics, Fed/central bank moves, sector policy shifts
Strict anti‑noise rules: no hot stocks, no meme assets, no conspiracy‑based picks
No hallucination: only official data, verified filings, and double‑sourced facts
Fully automated output: directly gives you buy‑ready symbols + position sizing

**Who This Is For**
Serious long‑term investors seeking high‑probability, low‑noise, forward‑looking global assets, without manual research or guesswork.
Guarantee
If no asset meets the ≥90% win rate criteria, the system returns “No qualified candidates” — no guesses, no speculation, no hype.

# 更新日志 (Changelog)

## [4.0.0] - 2025-06-30

### 🎯 版本主题
**实时数据驱动 + 自我进化学习系统**

从静态分析工具升级为动态进化的智能投资分析系统

---

### ✨ 新增功能

#### 1. 实时数据获取协议（第零章）
- **强制时间确认**：每次分析前必须确认当前日期时间
- **实时数据获取清单**：
  - 宏观政策（美联储/央行最新政策）
  - 市场指数（标普500、纳斯达克、沪深300、恒生等实时点位）
  - 估值数据（PE、PB、RSI等最新值）
  - 资金流向（北向资金、主力资金净流入/流出）
  - 地缘事件（中东局势、中美关系等最新进展）
  - 个股信息（股价、成交量、最新财报、公告）
- **数据验证规则**：建立★★★★★到★★☆☆☆的信息确定度评级体系
- **数据时效性红线**：使用过期数据（非当日/最新）直接排除

#### 2. 自我进化与学习系统（第八章）
- **学习机制架构**：
  - 自动记录分析日志
  - 标记待验证预测
  - 定期回顾总结
- **经验记录模板**：
  - 成功案例记录格式
  - 失败案例记录格式
- **策略自动优化规则**：
  - 根据预测准确性调整事件权重系数
  - 优化穿针识别、超跌判断的阈值参数
  - 建立数据源准确性评级体系
  - 根据市场环境调整仓位建议
- **学习反馈循环**：分析→记录→验证→总结→优化→更新

#### 3. 新增支持文件
- `learning_log.md` - 学习日志，记录成功/失败案例
- `strategy_updates.md` - 策略更新记录，追踪权重和规则变更
